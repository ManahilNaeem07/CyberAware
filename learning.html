Cybersecurity Learning Hub & Glossary

Core Learning Topics

Phishing

Deceptive emails and messages designed to trick you into revealing sensitive data like passwords or credit card numbers.

Learn More

Always check sender email addresses carefully. Watch out for urgent language, spelling mistakes, and unexpected attachments or links.

Malware

Malicious software such as viruses, ransomware, and spyware built to damage or gain unauthorized access to your system.

Learn More

Keep your operating system and antivirus software updated. Avoid downloading files or clicking links from unknown sources.

Password Security

The practice of creating strong, unique login credentials and using multi-factor authentication (MFA) to prevent breaches.

Learn More

Use long passwords combining letters, numbers, and symbols. Never reuse the same password across multiple websites.

Online Privacy

Safeguarding your personal data and digital footprint from unwanted tracking, surveillance, and data harvesting.

Learn More

Review privacy settings on social media platforms, use secure browsers, and be cautious about what personal details you share online.

Digital Scams & Social Engineering

Fraudulent tricks and psychological manipulation used by scammers to fool internet users into sending money or sharing private info.

Learn More

Be skeptical of unexpected prize winnings, urgent requests for money from unknown accounts, or offers that sound too good to be true.

Wi-Fi & Public Network Safety

The risks of connecting to unsecured public Wi-Fi networks in cafes, airports, or universities where hackers can intercept data.

Learn More

Avoid logging into sensitive bank accounts or entering passwords on public Wi-Fi unless you are using a secure VPN to encrypt your connection

Cybersecurity Glossary

Search for essential technical terms and definitions below:

  • Encryption: Converting readable data into an unreadable code to prevent unauthorized access during transfer or storage.
  • Firewall: A network security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules.
  • Malware: An umbrella term for any malicious software designed to disrupt, damage, or infiltrate computer systems.
  • Multi Factor Authentication (MFA): A security process where a user provides two or more verification factors to gain access to an account.
  • Phishing: A scoial engineering attack where criminals impersonate legitimate organizations to steal sensitive user information.
  • Ransomware: A type of malware that encrypts a victim's files, with the attacker demanding a ransom payment to restore access.
  • VPN (virtual private network): A tool that creates a safe, encrypted connection ober a less secure network like the internet.
  • Data Harvesting: The automated process of gathering large amounts of data from websites or online user profiles without explicit consent.
  • Social Engineering: Psychological manipulation techniques used by attackers to trick people into breaking security procedures or giving up confidential data.
  • Zero-Day Vulnerability: A newly discovered software flaw that hackers exploit before the creator or vendor has time to fix it.
  • Antivirus Software: A program designed to detect, prevent, and remove malware infections from your computer or mobile device.
  • Two-Factor Authentication (2FA): A security method requiring two distinct forms of identification for access (e.g., a password plus a code sent to your phone)
